How to Redact a PDF in Preview on Mac (and Why It Might Not Be Safe)

By CamLabs AI
November 13, 2026 · 5 min read

macOS Preview has a real Redact tool — not a fake black box, but an actual deletion of the underlying text. For simple text PDFs it works. The problems start the moment you have a scanned document, a long file, or more than a handful of sensitive values to find.

This guide walks through how to use Preview’s Redact tool correctly, explains where it falls short, and shows how to verify that a redaction actually worked before you send the file.

First: drawing a black shape is not redaction

Before getting into Preview’s Redact tool, it’s worth being clear about what it isn’t. Preview’s annotation tools let you draw filled rectangles and thick highlights. Those are shapes on top of the page — the text underneath remains in the file and can be selected, copied, and pasted out by anyone who opens the PDF.

That is a common failure mode. High-profile court filings have been unredacted with a simple copy-paste for exactly this reason. If you’ve been covering sensitive text with a black box from the Markup toolbar, the information is probably still there.

The Redact tool is different. It permanently removes the characters from the file when you save.

How to use Preview’s Redact tool

The Redact tool is available in macOS Ventura (13) and later. Here is the step-by-step process:

  1. Duplicate your file first. Work on a copy, not the original. Once a redaction is saved in Preview, it cannot be undone — there is no way to recover the removed text from the saved file.
  2. Open the PDF in Preview.
  3. Open the Redact tool. Go to Tools > Redact in the menu bar. A banner appears at the top of the window explaining that redactions are permanent when saved.
  4. Select the text to redact. Click and drag over the text you want to remove, just as you would to highlight it. The selection turns black immediately in Preview’s working view.
  5. Repeat for every instance. Continue selecting every piece of sensitive text across all pages. Preview will not search for patterns — you must find each one manually.
  6. Save the file. Choose File > Save (or Cmd+S). The redactions are applied and the underlying text is removed. This step is permanent.

When you reopen the saved file, the redacted areas appear as solid black rectangles. The text that was there is gone from the file entirely.

Important: save to a new filename. Even though Preview applies redactions on save, it is safest to use File > Export as PDF and give the redacted copy a distinct name, such as document-redacted.pdf. This keeps your original intact if you need to revisit it.

Where Preview’s Redact tool falls short

For a one-page letter with a single SSN in a known location, Preview’s Redact tool is fast and free. For anything more complex, its limitations matter.

  • No OCR — scanned documents cannot be redacted. Preview’s Redact tool works by selecting text in the PDF’s text layer. If the PDF is a scan (a photographed or photocopied page), there is no text layer for Preview to select. The cursor simply will not grab the characters. You cannot redact a scanned PDF in Preview.
  • No pattern search. Preview has no way to automatically find all Social Security numbers, account numbers, phone numbers, or other sensitive patterns. You must scroll through the entire document and identify every instance by eye. A nine-digit number in a footnote, a header on page 14, or a line wrapped across two lines is easy to miss.
  • No batch processing. There is no way to redact the same field across multiple PDFs at once. Each file must be opened and processed individually.
  • Easy to miss instances in long documents. A 40-page loan application or medical file will repeat SSNs, dates of birth, and account numbers many times — in headers, footers, tables, signature blocks, and exhibit stamps. Manual review of every occurrence is slow and prone to error.
  • Metadata, comments, and form fields are not cleaned. Preview’s Redact tool removes visible text from the page, but it does not strip the document title, author field, comments, annotations, or data stored in fillable form fields. A PDF can carry a person’s name in its metadata even after the visible text on every page has been redacted.

None of these are reasons to avoid Preview for simple jobs. They are reasons to know its limits before trusting it with a document that matters.

How to verify the redaction worked

Whatever tool you use, always test the saved file — not the working copy on your screen. The check takes about two minutes.

  1. The copy test. Open the redacted PDF, press Cmd+A to select all, then Cmd+C to copy. Paste into a blank TextEdit document. If any of the supposedly removed text appears in the paste, the redaction did not work.
  2. The search test. Press Cmd+F in Preview and search for something you removed — the first five digits of an SSN, an account number, a name. It should return no results.
  3. The click test. Try clicking or dragging across each black bar. If a cursor appears inside the bar and text gets selected, the underlying text is still there.
  4. Page-by-page visual check. Zoom in on every page. Watch for numbers that wrap to the next line, text in headers and footers, and anything in tables or stamps that may have been skipped.

When Preview is not enough

Two situations make Preview the wrong tool for the job:

Scanned documents. If your PDF was produced by a scanner, photocopier, or phone camera, Preview cannot redact it at all — there is nothing to select. See our guide on how to redact a scanned PDF on Mac for your options.

Documents with many sensitive values. Tax returns, HR files, loan applications, court exhibits, and medical records contain SSNs, account numbers, dates of birth, and addresses repeated across dozens of pages. Summary: what Preview does and doesn’t do

  • Does permanently remove text from the saved PDF — it is a real redaction, not a shape overlay.
  • Does not work on scanned PDFs because there is no text layer to select.
  • Does not search for patterns — you find every SSN, account number, and name yourself.
  • Does not clean metadata, form fields, comments, or annotations.
  • Cannot be undone after saving — always work on a copy.
  • Is free and built in to macOS Ventura and later — the right tool for a short, text-based PDF with a small number of items to remove.
