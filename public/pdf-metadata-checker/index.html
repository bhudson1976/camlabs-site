What this checks

  1. Document info. Title, author, subject, keywords, the app that made the file and the dates it was created and changed. The title is often the original file name.
  2. XMP metadata. A second, separate copy of document details that many apps write. Removing the visible properties alone often leaves this behind.
  3. Earlier versions. Many editors save changes by adding to the end of the file. Earlier versions, including text that was later deleted, can still be inside.
  4. Comments and markups. Sticky notes, highlights and their authors' names.
  5. Attachments. Files embedded inside the PDF.
  6. Form fields. Filled-in values, including ones that may be hidden or scrolled out of view.
  7. Scripts. JavaScript that runs when the file opens.

What the cleaned copy removes

You choose what to remove. The cleaned copy is rebuilt from scratch, so earlier saved versions are left out automatically. It does not change the text or images on the pages, and it does not redact anything. If a name or number is visible on the page, it is still there.

No tool is perfect, including this one. Open the cleaned copy and check its properties (File > Document Properties or Get Info) before you send it.
