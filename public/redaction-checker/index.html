What this checks

  1. Text under boxes. We draw each page the way a PDF viewer would, then look at every piece of selectable text. If a word sits under a solid box, it's still in the file and anyone can copy it out.
  2. Invisible text. Text that is selectable but can't be seen on the page, such as white text or a hidden OCR layer over a blacked-out area.
  3. Unapplied redaction marks. Some editors let you mark areas for redaction but only remove the content when you click "Apply." Marks that were never applied are flagged.
  4. Hidden details. The title, author and other document info (the title is often the original file name), a second copy of those details called XMP metadata, comments with their authors' names, attached files, filled-in form values and scripts.
  5. Earlier versions. Many editors save changes by adding to the end of the file, so earlier drafts can still be inside. The checker counts them.
  6. A cleaned copy. If hidden details are found, you can download a copy with them removed. It does not change what's on the pages, so it won't fix a failed redaction.

What it can't check

  • Pictures under a box. If a scanned image sits under a black rectangle, the original image may still be in the file. This tool only reads text.
  • Whether you blacked out the right things. A clean result means nothing is hiding under the boxes, not that every SSN or name on the page was covered.
  • Password-protected files. Remove the password first, then check the copy.

No checker is perfect, including this one. For anything important, also open the file, select all the text (Command-A or Ctrl-A), copy it, and paste it into a blank note to see what comes out.

How it stays private

The checker is a single web page. Your PDF is opened by code running in your own browser tab and is never sent to CamLabs or anyone else. You can turn off Wi-Fi after the page loads and it still works.
