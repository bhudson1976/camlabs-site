😊 Good news — Sentinel is safe to install

We get it: the internet is full of sketchy downloads, and we would never lump ourselves in with the crooks. So here's the honest scoop — Sentinel is brand-new, and our official code-signing certificate is still being issued. Until it's ready, Windows SmartScreen may flash an "unrecognized publisher" notice.

That's a reputation check, not a safety warning 👍 — SmartScreen flags any new app whose publisher hasn't built up download "reputation" yet, regardless of what's inside. The build is local-first, zero-telemetry, and byte-for-byte identical to what's published on this page — it audits entirely on your own machine and never phones home. 💙

1
Download the Windows .zip with the button above.
2
Extract: right-click the .zip → Extract All, then open the extracted Sentinel folder. (Running it from inside the .zip triggers Windows permission errors — always extract first.)
3
Run sentinel_auditor.exe. If you see "Windows protected your PC," click More info → Run anyway — that's the reputation prompt clearing, not a malware warning.

Activate: paste the license key from your email to bind the audit engine to your local hardware. That's it.
